## Notes

- **DoD 2 run-state caveat (recorded in [SELF-HOSTING.md](../SELF-HOSTING.md#soak-ws-k-stage-2-acceptance)):** the scheduled `self-review-loop` / `self-merge-prs` runs currently exit red at the `GH_TOKEN` assert because `secrets.GH_TOKEN` is not configured; the workflow log records the honest outcome (`GH_TOKEN not set`) and every soak PR was hand-merged by the lane leader under the single-identity I2 deviation, which the soak criterion records as the processing path. Configuring `GH_TOKEN` is the follow-up that lets the scheduled automations process PRs directly.
- **DoD 4 ADR link:** ADR-0001 lives in the toolkit's private research notes (the plan's home); the link is provided for traceability, not as a public artifact.
- **DoD 3 op count:** the generated reference and the `registry.test.ts` completeness check both read the same runtime registry the CLI dispatches from, so a new op cannot land without its subcommand and its doc.
