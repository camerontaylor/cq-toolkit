Bind the `@camerontaylor` scope to the npm registry before any registry read
or write. From npm 11 a configured `@camerontaylor:registry` overrides
`--registry`, so the absence check, the upload and the readback could each
target another registry while npmjs stays unchanged. Each block that runs an
npm registry command therefore validates the effective scope registry first
and refuses to continue unless it is npmjs or unset, and the block records the
npm version and that effective scope configuration.

```sh
scope_registry="$(npm config get @camerontaylor:registry)" || { echo "cannot read @camerontaylor:registry; aborting" >&2; exit 1; }
case "${scope_registry%/}" in
  https://registry.npmjs.org|undefined|"") ;;
  *) echo "@camerontaylor:registry is $scope_registry, not https://registry.npmjs.org/; refusing to treat any registry response as npmjs" >&2; exit 1 ;;
esac
echo "npm $(npm --version); @camerontaylor:registry ${scope_registry:-undefined}; registry $(npm config get registry)"
npm view @camerontaylor/cq-toolkit@0.2.0 version --registry https://registry.npmjs.org/
```

Proceed only after a verified registry `E404` absence response; an auth,
network, or other error is not absence. Record the printed npm version and
scope registry with the response.

commit and uses a fresh checkout. The shell exits on every failed gate.
Do not run the publication command while any placeholder or gate is open.

```sh
set -euo pipefail
git clone https://github.com/camerontaylor/cq-toolkit.git cq-v020-publish
cd cq-v020-publish
printf '%s' "$FINAL_02_SHA" | grep -Eqx '[0-9a-f]{40}'
test "$(git rev-parse origin/main)" = "$FINAL_02_SHA"
git checkout "$FINAL_02_SHA"
test "$(git status --porcelain)" = ""
test "$(node -p 'require("./package.json").version')" = 0.2.0
grep -qx "export const SERVER_VERSION = '0.2.0';" src/harness/mcp/server.ts
grep -qx "const CLIENT_VERSION = '0.2.0';" src/driver/acp/index.ts
scope_registry="$(npm config get @camerontaylor:registry)" || { echo "cannot read @camerontaylor:registry; aborting" >&2; exit 1; }
case "${scope_registry%/}" in
  https://registry.npmjs.org|undefined|"") ;;
  *) echo "@camerontaylor:registry must be npmjs or unset before any npm registry command" >&2; exit 1 ;;
esac
echo "npm $(npm --version); @camerontaylor:registry ${scope_registry:-undefined}"
export PNPM_CONFIG_VIRTUAL_STORE_TYPE=project
pnpm install --frozen-lockfile
pnpm run build
gitleaks dir --no-banner --redact .
npm whoami --registry https://registry.npmjs.org/
pack_dir="$(mktemp -d)"
pnpm pack --pack-destination "$pack_dir"
pack_file="$pack_dir/camerontaylor-cq-toolkit-0.2.0.tgz"
test -f "$pack_file"
expected_sha256="$(shasum -a 256 "$pack_file" | cut -d' ' -f1)"
echo "sha256 $expected_sha256"
expected_sha1="$(shasum -a 1 "$pack_file" | cut -d' ' -f1)"
echo "sha1 $expected_sha1"
expected_integrity="sha512-$(openssl dgst -sha512 -binary "$pack_file" | openssl base64 -A)"
echo "integrity $expected_integrity"
listing="$pack_dir/listing.txt"
tar -tzf "$pack_file" > "$listing"
cat "$listing"
violations="$(sed 's|^package/||' "$listing" | sed '/^$/d' | grep -vE '^(package\.json|README\.md|LICENSE|dist|policy)(/.*)?$' || true)"
test -z "$violations" || { echo "paths outside the files allowlist: $violations"; exit 1; }
grep -qx 'package/dist/index.js' "$listing"
grep -qx 'package/policy/denylist/patterns.yml' "$listing"
unpack_dir="$(mktemp -d)"
tar -xzf "$pack_file" -C "$unpack_dir"
gitleaks dir --no-banner --redact --config .gitleaks.toml "$unpack_dir/package"
npm publish --dry-run "$pack_file" --access public --registry https://registry.npmjs.org/
test "$(git status --porcelain)" = ""
```

```sh
set -euo pipefail
# Preflight the block's own dependencies BEFORE the dispatch, so a missing
# tool never leaves a dispatched run unpollled: jq for the verdict check,
# and gh >= 2.87.0 — the release that made workflow dispatch return the
# created run's URL, which the poll below binds to.
command -v jq >/dev/null || { echo "jq is required by this check"; exit 1; }
gh_ver="$(env -u GITHUB_TOKEN gh --version | sed -n '1s/^gh version //p' | cut -d ' ' -f1)"
[ "$(printf '2.87.0\n%s\n' "$gh_ver" | sort -V | tail -n1)" = "$gh_ver" ] || {
  echo "gh >= 2.87.0 is required (workflow dispatch must return the run URL)"; exit 1; }
# install-matrix.yml has no push trigger, so the
# promotion push yields no run on the release commit. Dispatch on main —
# workflow_dispatch --ref takes a branch or tag, not a SHA — immediately
# after promotion, when the tip of main is FINAL_02_SHA. gh prints the
# created run's URL: the poll reads that exact run, so no stale,
# concurrent or in-flight other run can be mistaken for it.
dispatch_url="$(env -u GITHUB_TOKEN gh workflow run install-matrix.yml --ref main)"
run_id="$(printf '%s' "$dispatch_url" | sed -n 's|.*/runs/\([0-9][0-9]*\).*|\1|p')"
[[ "$run_id" =~ ^[0-9]+$ ]] || {
  echo "dispatch returned no run URL — cannot bind the poll to this dispatch"; exit 1; }
# Only this run's completed success passes the gate, and its head_sha must
# equal FINAL_02_SHA: a main tip that drifted between the promotion and the
# dispatch fails loudly instead of auditing the wrong commit.
deadline=$((SECONDS + 3600))
conclusion=""
while true; do
  conclusion="$(env -u GITHUB_TOKEN gh api "repos/camerontaylor/cq-toolkit/actions/runs/$run_id" |
    jq -r --arg sha "$FINAL_02_SHA" '
      if .head_sha != $sha then "head-sha-mismatch"
      elif .status == "completed" then (.conclusion // "")
      else "" end')"
  test "$conclusion" = success && break
  if test -n "$conclusion"; then echo "install-matrix conclusion: $conclusion"; exit 1; fi
  test "$SECONDS" -lt "$deadline" || { echo "timed out waiting for install-matrix (run $run_id) on $FINAL_02_SHA"; exit 1; }
  sleep 30
done
echo "install-matrix success on $FINAL_02_SHA (run $run_id)"
```

## Owner publication and readback

After the owner verifies the preflight record and authorizes publication of
the audited bytes, publish that same tarball from the same checkout:

Re-assert the audited digest immediately before publishing; abort on any
mismatch (`expected_sha256`, `expected_sha1` and `expected_integrity` are the
values recorded during the audit, so re-export them from the preflight record
if the shell was restarted):

```sh
test "$(shasum -a 256 "$pack_file" | cut -d' ' -f1)" = "$expected_sha256" || { echo "tarball changed since audit; aborting"; exit 1; }
test "$(shasum -a 1 "$pack_file" | cut -d' ' -f1)" = "$expected_sha1" || { echo "tarball changed since audit; aborting"; exit 1; }
test "sha512-$(openssl dgst -sha512 -binary "$pack_file" | openssl base64 -A)" = "$expected_integrity" || { echo "tarball changed since audit; aborting"; exit 1; }
scope_registry="$(npm config get @camerontaylor:registry)" || { echo "cannot read @camerontaylor:registry; aborting" >&2; exit 1; }
case "${scope_registry%/}" in
  https://registry.npmjs.org|undefined|"") ;;
  *) echo "@camerontaylor:registry must be npmjs or unset before publishing" >&2; exit 1 ;;
esac
echo "npm $(npm --version); @camerontaylor:registry ${scope_registry:-undefined}"
npm publish "$pack_file" --access public --registry https://registry.npmjs.org/
npm view @camerontaylor/cq-toolkit@0.2.0 version dist.tarball dist.shasum dist.integrity --registry https://registry.npmjs.org/
test "$(npm view @camerontaylor/cq-toolkit@0.2.0 dist.integrity --registry https://registry.npmjs.org/)" = "$expected_integrity" || { echo "registry integrity differs from the audited tarball"; exit 1; }
test "$(npm view @camerontaylor/cq-toolkit@0.2.0 dist.shasum --registry https://registry.npmjs.org/)" = "$expected_sha1" || { echo "registry shasum differs from the audited tarball"; exit 1; }
```

The registry `dist.integrity` (SHA-512) must equal the audited tarball's
SHA-512 integrity; that is the binding comparison. The `dist.shasum` (SHA-1)
comparison is secondary. Save the registry listing and publish identity. Only then create and push annotated
`v0.2.0` on the verified toolkit source SHA through the reviewed release
procedure; record the remote tag target. No tag is created by this draft.
