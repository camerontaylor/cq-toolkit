Parent: [analysis and owner rulings](ownership-redesign-analysis-20261107.md).
Implement D after merged A, B and C; implement E after merged D. Rebase on their

not a second implementation. No further architecture decision is delegated.

## Fixed scope and owner decisions

- No repository-wide lock. Exclusion is per original-repo PR slot and actual
  checkout; one metadata file per slot, no shared mutable JSON map.
- Use C's private fs-ext flock adapter on Linux/macOS, with C's packaging CI.
  No CLI helper, heartbeat reclaim, PID-based reclaim or unlocked fallback.
  O_EXLOCK remains a separate fallback only if native packaging fails.
- Local disks only; network/FUSE/SMB/host-shared mounts are unsupported until
  tested on the actual mount. Do not claim mount support from platform alone.
- Pass held descriptors to controlled writers. Durable incomplete state covers
  process death and paths whose descendant descriptor lifetime is not guaranteed.
- Keep original-repo PR exclusion for bulk's unique clones; B's explicit remote
  leases provide cross-host correctness. Preserve B's fast-forward-only policy.
- Checkout exclusion covers participating review.address/review-loop paths.
  Generic fix and the entirety of dev.cycle are outside this contract.
- Keep A's actual-task drain, terminal capabilities, evidence and report rules.
  Remove authority history, not failed-attempt commits or queue provenance.

### D5. Incomplete-state and cancellation protocol

1. Acquire and inspect each required slot; call C assertReusable on predecessors.
   Missing metadata is a fresh admission only after normal Git identity/content
   validation. Malformed metadata refuses that slot without replacing bytes.
2. Before **any mutator**, write incomplete=true durably on all acquired slots,
   including unbound slots. Then dispatch inside A's tracked lifetime. Failed
   persistence starts zero writers. Scope includes controlled writers too, so
   power loss never depends on receipt reconstruction or fd inheritance alone.
3. Stop admissions on cancellation. Await actual tracked driver/tool/child work,
   then A terminal settlement; retain failed-attempt commits before verified
   restoration and persist reports. Existing opaque-write-set refusal stays.
4. Set incomplete=false only after A confirms actual drain, all terminal work
   and final report/bookkeeping IO is settled, no opaque unresolved writer or
   pending recovery remains, and slot/checkout identities still match. Normal
   driver completion uses its existing awaited close/teardown contract; adding
   fd passing does not certify unobserved descendants. If that contract cannot
   account for a writer, leave incomplete, including on otherwise normal exit.
   Ordinary needs-human from a fully settled gate failure may clear; an error
   alone is neither proof of quiescence nor a reason to erase work.
5. Clear checkout/resolver metadata first; original coordination PR slot last.
   No checkout mutation follows clearing its flag. Crash between clears leaves
   some false and some true: admission must check every participating slot,
   so true still refuses. A later unrelated checkout/PR remains runnable.
6. Close parent descriptors only after drain. On drain deadline/unknown writer,
   keep incomplete=true and retain strong references to the held FileHandles
   in the unresolved task tracker until actual close, even if public result already returned
   needs-human. Process exit releases only this process's references. Do not
   call LOCK_UN, emit a clean completion certificate, or delete partial state.

| Crash/recovery case | Required behavior |
|---|---|
| SIGSTOP/suspend | Contender is busy; no heartbeat reclaim or timer-based steal. |
| Node SIGKILL, fd-inheriting child alive | Slot remains busy until last inherited reference closes; later admission still sees incomplete and refuses reuse. |
| Node SIGKILL, opaque/non-inheriting descendant alive | Lock may become acquirable; C assertReusable still refuses before any second writer. Clean status is insufficient. |
| Crash during first clone/add/remove | Original PR metadata remains unbound/true or last bound/true. Inspect partial checkout; do not rerun create or prune automatically. |
| Reboot/power loss or torn metadata/report | Preserve source/index, temp metadata, refs and reports; malformed or incomplete slot refuses. Never claim a cancelled failed-attempt receipt was reconstructed. |
| Completed failed-attempt commit, later restore/report failure | Keep ref and bytes, keep incomplete; expose recorded immutable evidence and path without claiming completed restoration. |
| Quiescent dirty/unpushed worktree | Refuse destructive refresh/reuse; preserve bytes/commits. Human reconciles without silent reset/force-remove. |

No automatic recovery API/flag is added. E's operator procedure acquires the
same C slot for inspection, establishes writer quiescence without PID-age
heuristics, preserves outstanding work and reconciles Git. Only then may it
write the matching bound/false or removed unbound/false. Lock acquisition alone
allows inspection, not reuse or automated clearing.

### E migration and recovery behavior

Old files are preserved byte-for-byte: owner.json, .store, .lock directories,
retired/bootstrap generations, common cq-review-address-worktrees.json,
journal worktrees.json and selfhost worktree-registry.json. Never auto-delete,
rotate, validate as current authority or infer safety from their age. Offline
old-binary quiescence in D6 is a deployment prerequisite, not an enforced
repo-wide runtime barrier. Active/quarantined old checkout work must be inspected
before migration; preserve it and leave matching new slot incomplete if uncertain.

Importer replaces D's temporary migration refusal. Under held requested PR
slot and only when C readMetadata is absent, examine known registry sources in
order: original-common registry, explicit caller's journal registry, selfhost
journal registry if applicable. Caller supplies exact old paths; do not walk
other directories. Treat data only as cached checkout hints. Bounds: 1 MiB
per legacy file before parsing, object map, own decimal requested key, valid
path/branch strings; ignore unrelated entries, never deserialize capability.
Missing requested entry permits ordinary safe Git discovery. A corrupt bounded
file or conflicting requested-key paths refuses this PR with retained bytes
and a path diagnostic; unrelated new metadata bypasses legacy reads entirely.
Do not create a new global “migration complete” marker.

For a hint, require current canonical root containment, actual Git-dir/common
identity, expected review label/head and all D dirty/unpushed checks. A foreign
or ambiguous requested hint refuses without removal; a missing clean old path
is stale and permits existing resolver discovery/create. Read legacy hints
before the first new metadata write; keep the selected candidate in the current
private run while D writes incomplete before fetch/resolve mutations. Register
a verified imported candidate as bound/true during that run, and clear only at
D's final drain. Import does not get an early bound/false exemption. Once new metadata exists,
it wins even if unbound or incomplete: never fall back to old “complete” hints.
Preserve old pointers until new registration succeeds. Import is idempotent,
per requested slot, and never rewrites a different slot's metadata.

Operator recovery document must give this exact procedure: stop owned old
admissions; drain/establish actual writer quiescence including opaque children;
acquire C's same affected slot(s); inspect index/status including ignored and
untracked files, ahead commits, failed-attempt refs, candidate dirs and reports;
preserve/pin outstanding user work without inventing authenticated receipts;
reconcile or remove only the intended clean checkout using existing non-forced
Git primitives; write bound/false for verified retained identity or unbound/false
after complete removal; close descriptors. If quiescence cannot be established,
leave incomplete and return to operator. No new recovery override CLI is added.

Document loss of historical clean-completion certificates, supported local
Linux/macOS storage/native dependency, no stale-lock deletion, descriptor and
opaque-child caveats, separate generic-fix/dev.cycle boundary, legacy API
replacement, per-slot manual recovery, and B's fast-forward explicit lease.
